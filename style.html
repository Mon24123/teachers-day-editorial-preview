VISUAL NOTEBOOK / 01

把温柔，
做成可以复用的设计。

参考《一位“爱花女士”的自白》的视觉语言：一张纸、一根线、一处轻轻落下的颜色。让文字保有呼吸，让交互承担叙事，把品牌藏进体验里。

01 / 颜色不多，情绪很完整

#FAF9F5

纸白占绝大部分。藏蓝建立秩序，粉色负责提醒情绪，绿色只提供一点生活感。彩色用于背景与笔触，正文始终用深色保证可读性。

02 / 先读懂它为什么好看

01

留白是停顿，不是空着

标题与画面之间留出一口气；一段只讲一个感受。重要句子周围的空白越足，越不需要放大字号或堆装饰。

02

手绘负责亲近，排版负责清楚

细线、轻微不规则的笔触让画面有人的温度。正文仍使用清晰的系统黑体，标题可少量用楷体；不让整页手写字牺牲阅读。

03

画面有情节，装饰有节制

一本作业、一只举起的手、一段倾听，都能对应一句文案。叶子和色块只陪衬，不替代真实场景，不把故事画成泛泛的氛围图。

04

交互给人一个理解的瞬间

参考文把“戴上眼镜”做成点击后的画面变化。本稿沿用这种表达逻辑：切换清晰视觉示意，再读产品带来的场景价值。

03 / 一段内容，四个节拍

场景先行

看见一双眼，
多一点回应

低头看教案，抬头看板书。
老师想及时接住，每一个疑问。

近远视线切换更流畅。
从题目到学生，关照跟得上目光。

第一拍 · 人
一句小标题，先点明人物的期待，不先报产品技术。
第二拍 · 事
两到四行生活细节，让读者知道困扰发生在什么时候。
第三拍 · 体验
一张对应场景的插画，一次能理解的画面变化。
第四拍 · 回应
一句核实过的产品价值，加一句落回人物的情感收束。

04 / 用在作品集，怎么迁移

PORTFOLIO / PROJECT NOTE从一次观察，
到一份真实行动。

把“场景 → 困扰 → 产品价值”，改为“观察 → 我的动作 → 证据”。

以真实项目照片或记录作为主画面，细线与纸感留作旁注。页面可保留这种舒缓的节奏，项目事实、角色边界和结果仍用清晰、可核验的文字呈现。

AI 插画适合封面和概念解释；项目成果页优先放实物、截图、现场记录。用图说明经历，避免用氛围替代证据。

项目封面
大留白 + 一句具体项目主张 + 一张主视觉。不把所有技能和指标塞进首屏。
项目过程
每一段一件事，关键动作做笔触标记；流程、现场照片与产出交替出现。
项目结果
结果和证据先行；外链用低调但清楚的文字入口，不需要每张卡片都放满按钮。
页末收束
用一两句话说明这段经历改变了什么，留下联系或查看完整材料的入口。

05 / 可以直接带走的基础规格

背景       #FAF9F5 / 纸感噪点不透明度 2.7%
标题       #172750 / 宋体或楷体 / 28—64 px
正文       #343740 / 苹方或微软雅黑 / 12—15 px
强调       #F4D6DE / 轻微倾斜的局部笔触
线稿       细藏蓝轮廓 / 无重阴影 / 少量水彩
段落       行高 2.1—2.3 / 每段 2—4 行
文章宽度   桌面 720 px / 手机占满宽度
内容边距   桌面 52—70 px / 手机 25—28 px
段落节奏   人物期待 → 场景 → 体验 → 价值
动态       点击后变化 / 650 ms / 支持减少动态

网页里的文字保持可选中、可复制。插画单独保存，别把整篇文案烘焙成一张图片；未来改字、换场景、调整手机排版会更容易。
