VISUAL NOTEBOOK / 01

喜欢的风格，
留下一本样本册。

从《一位“爱花女士”的自白》里记下喜欢的细节：纸感、细线、浅浅的粉色，还有点击眼镜后的变化。前面拆做法，后面放十个可以直接看的例子。

01 / 颜色不多，情绪很完整

纸白
#FAF9F5
画面与阅读底色

藏蓝
#172750
标题、线稿、关键句

浅粉
#F4D6DE
每屏一处的笔触

鼠尾草绿
#D5E1D6
植物与安静的陪衬

墨灰
#343740
长句与正文阅读

纸白占绝大部分。藏蓝建立秩序，粉色负责提醒情绪，绿色只提供一点生活感。彩色用于背景与笔触，正文始终用深色保证可读性。

02 / 先读懂它为什么好看

01

留白是停顿，不是空着

标题与画面之间留出一口气；一段只讲一个感受。重要句子周围的空白越足，越不需要放大字号或堆装饰。

02

手绘负责亲近，排版负责清楚

细线、轻微不规则的笔触让画面有人的温度。正文仍使用清晰的系统黑体，标题可少量用楷体；不让整页手写字牺牲阅读。

03

画面有情节，装饰有节制

一本作业、一只举起的手、一段倾听，都能对应一句文案。叶子和色块只陪衬，不替代真实场景，不把故事画成泛泛的氛围图。

04

交互给人一个理解的瞬间

参考文把“戴上眼镜”做成点击后的画面变化。本稿沿用这种表达逻辑：切换清晰视觉示意，再读产品带来的场景价值。

03 / 一段内容，四个节拍

场景先行

看见一双眼，
多一点回应

低头看教案，抬头看板书。
老师想及时接住，每一个疑问。

近远视线切换更流畅。
从题目到学生，关照跟得上目光。

第一拍 · 人
一句小标题，先点明人物的期待，不先报产品技术。
第二拍 · 事
两到四行生活细节，让读者知道困扰发生在什么时候。
第三拍 · 体验
一张对应场景的插画，一次能理解的画面变化。
第四拍 · 回应
一句核实过的产品价值，加一句落回人物的情感收束。

04 / 用在作品集，怎么迁移

PORTFOLIO / PROJECT NOTE从一次观察，
到一份真实行动。

把“场景 → 困扰 → 产品价值”，改为“观察 → 我的动作 → 证据”。

以真实项目照片或记录作为主画面，细线与纸感留作旁注。页面可保留这种舒缓的节奏，项目事实、角色边界和结果仍用清晰、可核验的文字呈现。

AI 插画适合封面和概念解释；项目成果页优先放实物、截图、现场记录。用图说明经历，避免用氛围替代证据。

项目封面
大留白 + 一句具体项目主张 + 一张主视觉。不把所有技能和指标塞进首屏。
项目过程
每一段一件事，关键动作做笔触标记；流程、现场照片与产出交替出现。
项目结果
结果和证据先行；外链用低调但清楚的文字入口，不需要每张卡片都放满按钮。
页末收束
用一两句话说明这段经历改变了什么，留下联系或查看完整材料的入口。

05 / 可以直接带走的基础规格

背景       #FAF9F5 / 纸感噪点不透明度 2.7%
标题       #172750 / 宋体或楷体 / 28—64 px
正文       #343740 / 苹方或微软雅黑 / 12—15 px
强调       #F4D6DE / 轻微倾斜的局部笔触
线稿       细藏蓝轮廓 / 无重阴影 / 少量水彩
段落       行高 2.1—2.3 / 每段 2—4 行
文章宽度   桌面 720 px / 手机占满宽度
内容边距   桌面 52—70 px / 手机 25—28 px
段落节奏   人物期待 → 场景 → 体验 → 价值
动态       点击后变化 / 650 ms / 支持减少动态

网页里的文字保持可选中、可复制。插画单独保存，别把整篇文案烘焙成一张图片；未来改字、换场景、调整手机排版会更容易。

07 / 看例子，比看规则更明白

下面把前面的做法各做一遍。作品集内容是排版演示，换成自己的真实项目后再使用。

封面留白字与强调场景文案点击交互作品集首页项目过程结果与证据页末收束换一套配色
01

一张封面，先说一件事

大标题、两行短文、一张主视觉。封面先让人愿意读下去。

教师节 · 推文封面

老师，
这一次，
也看见您。

黑板上的字，作业里的批注，
您总想让我们看得更明白。

换到作品集：标题写你在做什么，旁边放一张能说明项目的图片。次要信息留到下面。

02

同样的内容，试试留白

点下面的按钮，看看字号没变时，间距怎样影响阅读。

课堂的一刻

举起又放下的手，
老师也看见了。

一道题讲完，总要再问一句。
每一次犹豫，都值得一点耐心。

空白让这一句，有时间被读完。

03

标题有表情，正文要好读

只给一个词上颜色，避免整段都在争夺注意力。

宋体 · 封面

从一个问题，
开始认真观察。

适合开篇和项目主张，字数少时更有停顿。

楷体 · 章节

慢一点，
看清发生了什么。

适合短标题。正文使用清楚的黑体，避免整页都像手写笔记。

一句话里的强调

不是给整段文字涂颜色，
而是把你最想留下的那个词，轻轻圈出来。

04

场景写清楚，产品才进得来

先让人看见发生了什么，再用一句产品价值回答它。

场景 → 用眼困扰 → 产品回应

教案在屏幕上，
作业在手边。

备课、批改，一页接着一页。
看小字渐渐费力，近中距离还要来回切换。

万里路® XR系列，
让一臂距离内视物清晰。

为什么不用“高科技护眼神器”？

它没有说明老师遇到了什么问题，也没有给出核实过的产品能力。“教案和作业之间来回看”更具体，读者能想起自己的日常。

05

用一次点击，讲清一次变化

按钮不是装饰。点一下，画面变化；再点一下，可以复原。

这是模糊滤镜与线框切换的创意演示，不是镜片测量。原公众号使用 SVG 点击交互；普通网页可以用 CSS 和 JavaScript 实现类似的叙事。

06

沿用纸感与留白，主张换成项目本身。下面是虚构的版式示例。

作品集版式示例 / 项目笔记

把一次讨论，
变成一次尝试。

从问题出发，记录怎么想、怎么做，
再把验证的过程留下来。

真正使用时，右侧换成项目实物、现场照片或截图。这张纸只负责排版示意，不充当项目证据。

07

项目过程，把动作讲清楚

点三个阶段，看看一页过程记录可以怎样切换。内容是示范，不是你的经历。

先把问题看清

材料散在哪里？
谁会用到它们？

列出资料类型、使用场景和查找路径。
先知道大家怎样找材料，再决定怎么整理。

这一阶段留下访谈记录 / 资料清单 / 原始截图

没有真实数字就不放数字。做过什么、留下什么，也可以讲得很清楚。
