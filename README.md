# 老师，这一次，也看见您

教师节公众号推文视觉提案。纸感底色、藏蓝线稿与原创 AI 插画；三个眼镜按钮支持清晰视野概念切换。

在线预览：https://mon24123.github.io/teachers-day-editorial-preview/

风格拆解：https://mon24123.github.io/teachers-day-editorial-preview/style.html

## 文件

- index.html：推文预览
- style.html：风格拆解与作品集迁移方法
- styles.css：配色、字体、布局与响应式样式
- app.js：视觉切换、阅读进度与打印
- assets/：原创插画与纸感底纹
- 文案.txt：纯文案
- 风格复用指南.md、插画提示词.md：设计说明与 ImageGen 提示词

## 内容说明

个人笔试视觉提案，非依视路官方发布页面。插画由 ImageGen 新生成，文字与页面代码可编辑；视觉交互为概念示意，不代表实际镜片测量或效果模拟。

产品描述参考依视路万里路 XR 官方页面：https://www.essilor.com/cn-zh/products/varilux/varilux-xr-series/

静态网站，无账户、表单、分析脚本或第三方依赖。支持手机、键盘操作与减少动态设置。
